NexOS 2.1 (fixed + v1 Settings + Storage Picker)

Python desktop environment, not a bootable kernel OS.

Run:
1. Open run_nexos.bat  (or: python main.py)

Storage:
- User Storage is the Storage folder (20 MB quota).
- File Explorer: create, rename, copy, move, delete, Back, Forward, Up.
- Drag files onto folders to move them.
- Every file type has its own icon.

Storage Picker (same UI as File Explorer):
- Used in Code Editor, Notepad, Photos, Media Player, Paint, Settings (wallpaper).
- Open / Save / Choose folder — only from Storage.
- Filters for .py, .txt, .mp3, .mp4, images, etc.

Settings (v1 features restored):
- Username, Theme (incl. Nex Dark), Accent color
- 15 background animations: None, Aurora, Stars, Bubbles, Matrix, Grid, Rain,
  Orbit, Particles, Waves, Pulse, Snow, Fireflies, Spectrum, Comets
- Custom background color, Wallpaper image from Storage
- Language, Volume, Airplane mode, Notifications
- Backup export / import ZIP

Apps each have their own logo.
Code Editor: Open/Save via Storage Picker, Run .py with output panel.
Photos & Media Player: Storage only + camera.
